- 🔤 خط IBM Plex Sans Arabic — نفس خط الموقع بالضبط

- 🎬 حركات سلسة في كل مكان (انتقالات، دخول متدرج، عدادات، شيمر)
- 📶 شريط مراقبة الاتصال الفوري + رسائل خطأ واضحة
- 🔐 تسجيل الدخول بجوجل يعمل الآن داخل التطبيق
- 🛡️ صلاحيات كاملة (كاميرا/إشعارات/واتساب/هاتف)

## 📲 طريقة التثبيت

1. حمّل ملف الـ APK من الرابط بالأعلى
2. افتح الملف من إشعارات الجهاز أو من مجلد التنزيلات
3. اسمح بالتثبيت من مصادر غير معروفة (مرة واحدة فقط)
4. اضغط "تثبيت" وانتظر انتهاء التثبيت
5. افتح تطبيق **حصتي** وسجّل الدخول بحسابك على hassty.site
