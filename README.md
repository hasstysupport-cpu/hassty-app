## 🆕 ما الجديد في v1.2.1

### 🛡️ إصلاح جذري للشاشة البيضاء — ضمن نسخة APK رسمية أخيرًا
- السبب الفعلي للشاشة البيضاء كان في شريط التنقل السفلي (Column بلا min + قيمة SafeArea مفخمة من النظام) فيبتلع الشاشة كلها — **هذا الإصلاح اكتُشف بعد نشر v1.2.0، لذا نسخة v1.2.0 المثبتة عندك لا تحتويه — v1.2.1 تحتويه**
- شاشة بداية بهوية المنصة (الشعار + خلفية كريمي) بدل الأبيض الصامت
- أي خطأ غير متوقع يظهر ببطاقة واضحة (زر إعادة محاولة + نسخ التفاصيل) — لا بياض صامت بعد اليوم
- صفحة الإشعارات تعرض رسالة خطأ واضحة مع زر إعادة المحاولة بدل الفراغ

### 🪄 إصلاحات الورقة المدرسية (notebook) + التنبيهات
- إصلاح انزياح ارتفاع الورقة المدرسية + حالات خطأ/فراغ صريحة بأزرار إعادة المحاولة

### 🐞 إصلاح على الخادم: إرسال رموز التحقق
- تم اكتشاف وإصلاح خلل على خادم الموقع كان يُسقط endpoint إنشاء الحساب (`/api/auth/register`) برمز 500 بسبب استيراد وحدة واتساب قديمة محذوفة (`green.js`) — **بسبب ذلك لا يصل إطلاقًا رمز تفعيل الحسابات الجديدة**
- بعد الإصلاح: إنشاء الحساب يعمل، ورمز التفعيل (signup_verify) يُرسل فعليًا، ورمز استعادة كلمة المرور (password_reset) يعمل — تم التحقق بمحاكاة تسجيل حساب حقيقي واستلام الرمز عبر البريد

## 📲 طريقة التثبيت

1. حمّل ملف الـ APK من الجدول أعلاه
2. اسمح بالتثبيت من مصادر غير معروفة (إعدادات الأمان)
3. ثبّت وافتح — وسجّل بحسابك أو بجوجل بضغطة واحدة
4. لو ظهرت رسالة "التطبيق غير مثبت" → احذف النسخة القديمة أولًا ثم أعد التثبيت
