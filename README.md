- **الشاشة البيضاء اتصلحت للأبد** — السبب: شريط التنقل كان بياخد الشاشة كلها ويغطي المحتوى (اتكشف بالمشاكسة على مقاس جهازك واتصلح + 8 اختبارات آلية ناجحة)
